# Replace the live site with V8

This ZIP is root-ready. Do not upload the ZIP itself and do not upload an enclosing folder.

1. In the GitHub `alumni-map` repository, delete the current `index.html`, old CSS/JS files, old images, and any old asset folders.
2. Extract this ZIP locally.
3. Upload every extracted item directly to the repository root: `index.html`, `styles-v8.css`, `app-v8.js`, `.nojekyll`, `assets`, and this guide.
4. Commit the changes to `main`.
5. In the repository Actions tab, confirm the newest Pages deployment corresponds to that commit.
6. Verify the lower-right badge reads `UNBRANDED MOCK-UP · V8`.

The V8 badge is intentionally included as a deployment verification marker and can be removed after validation.
